# Tablero Kanban — Flujo Visual de Trabajo (EduConnect)

> Kanban es un método visual para gestionar el flujo continuo de trabajo. Cada tarjeta representa una actividad técnica o historia de usuario y se desplaza entre columnas conforme evoluciona su estado.

El tablero Kanban se utiliza para el control y seguimiento diario de todas las tareas del proyecto **EduConnect**, permitiendo al equipo coordinar esfuerzos y visualizar cuellos de botella en tiempo real.

---

## 1. Modelo de Columnas del Tablero

El tablero se encuentra configurado en Trello con las siguientes columnas estándar:

1. **TO-DO:** Tareas planificadas para el sprint listas para iniciar.
2. **BLOCKED:** Tareas que presentan impedimentos técnicos, dependencias no resueltas o bloqueos externos.
3. **IN PROGRESS:** Tareas que actualmente están siendo desarrolladas por un miembro del equipo.
4. **TEST/QA:** Tareas que han sido terminadas a nivel de código y se encuentran bajo pruebas unitarias, de integración o revisión por pares.
5. **DEPLOY:** Tareas integradas exitosamente a la rama de integración (`develop`) o liberadas.
